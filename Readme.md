# <center>IP Monitor软件说明1.0</center>

本软件基于 Python 开发，用于实时监测接收机网页连通情况。

## 1. 软件介绍
GNSS接收机数据流有时虽正常，但数据采样率过高不易看出异常情况，接收机网页端可以实时监测数据通讯正常与否。

## 2. 多维多策略探测（HTTP、TCP Port、Ping、Auto）
GNSS 接收机的品牌和网络配置极其多样（有的未启用 Web 页面，有的使用了特殊 Ntrip 发送端口如 2101/8000，有的开启了页面密码保护）。
我们在代码中增加了四种检测策略，并支持在 ip.config 配置文件中通过第三列可选参数直接进行指定（如不写则默认为 AUTO 智能自适应混合检测）：
1. HTTP：先执行 HEAD 探测（极省带宽），失败时自动降级到 GET。任何 < 500 的返回码（包含 401 密码未授权、403 禁止访问、302 跳转）均被判定为存活（代表 Web 服务在线）。
2. TCP:端口（例如 TCP:8000、TCP:2101）：利用 socket 尝试对指定端口进行握手连接，特别适用于未开启 Web 页面但开放了 Ntrip 服务端口的接收机。
3. PING：兼容 Windows / Linux 系统底层的 ICMP 探测。
4. AUTO（默认自适应）：按照 HTTP -> TCP:80 -> Ping 的顺序链式尝试，任意一种连通即判定在线，兼顾最大兼容性与零配置上手。

## 3. ip文件配置
站点名称 IP地址 [检测策略(可选，默认AUTO)]
ZRJD 192.168.1.100 HTTP<br>
ZHSH 192.168.1.101 PING<br>
ZHHY 192.168.1.102 TCP:8000<br>
ZHDH 192.168.1.103 AUTO<br>
......

## 4. 软件使用
ip.config与exe需放置在同级目录下，双击exe即可运行，默认是配置ip.config，也可自选其他ip.config，开始监控即可连续监测。
